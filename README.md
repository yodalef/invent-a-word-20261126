A Python program that coins a word we need — "almostalgia", nostalgia for a life you almost lived: the train just missed, the job nearly taken, the you that exists only at 2 a.m. — and writes the word with its one-line definition to /output/entry.txt. The line is UTF-8 text of 137 characters, within the bounty's 140-character limit. Deterministic and offline: no network use.

## Run it

```sh
python3 main.py
```

Writes the line to /output/entry.txt (or ./output/entry.txt when /output is not writable).
